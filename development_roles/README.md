## 공동 목표

8주 종료 시 다음 시연 흐름이 실제 서버와 DB를 사용해 동작해야 한다.

1. 회원가입 또는 로그인
2. 오늘의 습관 확인 및 완료 처리
3. 식사와 영양소 기록
4. 의약품 사전 검색 및 상세 조회
5. 사전의 의약품을 개인 복약 항목으로 등록
6. 복약 일정 확인 및 실제 복용 기록
7. 식사 완료 시각을 기준으로 식후 복약 예정 시각 계산
8. 일간·주간 기본 통계 확인

## 공동 협업 규칙

1. 기능 구현 전에 API 계약을 먼저 합의한다.
2. API 계약은 OpenAPI 문서 또는 요청·응답 JSON 예제로 관리한다.
3. 날짜와 시간은 서버에서 UTC로 저장하고 앱에서 사용자 시간대로 표시한다.
4. 상태값은 자유 문자열이 아니라 합의된 코드만 사용한다.
5. 프론트엔드는 DB에 직접 연결하지 않는다.
6. 백엔드 응답 변경 시 성준이 먼저 계약 문서를 수정하고 현서에게 알린다.
7. 화면 요구사항 변경 시 현서가 사용자 흐름과 필요한 데이터 변경을 성준에게 먼저 전달한다.
8. 각자 별도 Git 브랜치에서 작업하고 검토 후 병합한다.
9. API 키, 비밀번호, 토큰은 저장소에 커밋하지 않는다.
10. AI가 생성한 코드는 빌드와 테스트를 통과한 뒤에만 병합한다.

## 기능 완료의 공통 기준

기능 하나가 완료되었다고 판단하려면 다음 조건을 모두 만족해야 한다.

- 정상 시나리오가 실제 API와 DB에서 동작한다.
- 입력값 누락과 잘못된 값이 처리된다.
- 로딩·빈 결과·오류·재시도 상태가 화면에 존재한다.
- 다른 사용자의 데이터에 접근할 수 없다.
- 중복 요청으로 데이터가 이중 생성되지 않는다.
- 주요 동작이 테스트되었고 시연 절차가 문서화되어 있다.
- 앱과 서버 로그에 비밀번호·토큰·민감 건강정보 원문이 남지 않는다.

## 권장 회의 방식

- 매일 10분: 전날 완료, 오늘 작업, 막힌 문제 공유
- 주 2회: 실제 앱과 API를 연결한 통합 확인
- 매주 마지막 날: 시연 가능한 결과물 확인 및 다음 주 범위 고정
- 6주차 이후: 신규 기능 추가보다 오류 수정과 시연 안정성을 우선
