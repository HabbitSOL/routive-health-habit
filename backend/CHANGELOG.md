## 2026-10-14 — 인증 보완과 실DB 검증

### 변경

- auth_sessions와 JWT sid를 연결해 로그아웃·재설정·탈퇴 시 액세스 토큰까지 즉시 차단
- V5 마이그레이션 추가: 기존 세션 없는 토큰 폐기 및 재로그인 필요
- 사용자 단위 DB 잠금과 READ_COMMITTED로 갱신·이메일 인증·재설정의 동시 처리 직렬화
- 갱신 토큰의 저장되지 않은 객체 참조 오류 수정
- 메일 발송 간격 기본 60초, 재발급 시 이전 링크 무효화
- Google 필수 클레임 검사 및 Kakao 앱 ID·만료·사용자 ID 대조, 외부 호출 타임아웃
- 공통 인증 오류 JSON, 잘못된 JSON·중복 요청·동의 검증, 비밀번호 UTF-8 72바이트 제한
- 이메일 인증·재설정 링크 화면 및 로컬 SMTP 전송 테스트
- 재현 가능한 격리 MariaDB 검증 스크립트와 AUTH_SETUP.md
