# 승인 시안 적용 기록

2026-10-15 사용자가 SOL 로그인·오늘·습관 이미지 시안을 승인했다.

## 적용

- 흰색 배경(사용자 후속 요청 반영), 짙은 녹색 중심색, 식사 피치·복약 라벤더 보조색.
- 로그인·회원가입·프로필: 흰색 바탕에 Compose Canvas로 직접 그린 낮은 대비의 식물 패턴, 한국어 제목, 둥근 입력창과 버튼. 후속 참고 이미지의 여백과 단순한 입력 구조를 반영했습니다.
- 홈: 실제 기기 날짜에 맞는 주간 표시, 빈 기록 요약, 습관·식사·복약 카드.
- 오늘 / 기록 / 통계 / 내 정보 하단 메뉴. 내 정보는 프로필 표시·편집 데모를 연결했고 통계는 후속 개발 범위입니다.
- 회원가입: 계정 입력·동의 선택·인증 체험·로그인 체험 후 프로필을 설정하는 순서. 원문 미준비 상태와 데모임을 명시합니다.
- 내 정보: 민트 계열 헤더, 이니셜 아바타, 프로필 및 선택 건강정보, 기록 바로가기, 개인정보 메뉴. 타 앱의 캐릭터·로고·화면 이미지는 사용하지 않습니다.
- 습관: 예시 카드, 전체·진행 중·완료 필터, 화면 데모용 완료 전환.
- 광고: 실제 광고 요청 없이 명확히 표시된 정적 예시. 홈 데모 도구에서 숨김/표시 가능.
- 오류·로딩·재시도와 데모 종료 유지. 홈의 데모 도구를 펼치거나 내 정보에서 종료.

## 이미지와 구현 차이

생성 시안은 분위기·배치 기준이다. 기기별 화면 크기와 글꼴에 맞춰 스크롤한다.
시안의 예시 숫자를 실제 기록처럼 표시하지 않는다. 홈은 미등록 상태, 습관은 명시적인 예시다.
로그인은 입력 형식만 확인하며 실제 인증은 하지 않는다. 습관 변경은 로컬 데모 UI 상태로만 유지되고 홈 집계에 반영되지 않는다.
날짜 영역은 이번 단계에서 오늘 표시용이며 과거 조회 기능은 없다.
실제 광고 SDK, 개인정보 동의, API, 저장 기능을 추가하지 않았다.

## 에셋 출처

습관 카드 전용 `habit_stretch.png`, `habit_water.png`, `habit_walk.png`는 각 활동에 맞춰 image_gen으로 새로 생성한 수채화 스타일 일러스트다. 카드 오른쪽에 전체 그림이 들어가도록 맞춰 인물과 물잔이 잘리지 않게 배치했다. 문구와 동작은 유지했다.

`app/src/main/res/drawable-nodpi/sol_morning.png`: 이 프로젝트를 위해 image_gen으로 새로 생성한 일러스트. 창가, 햇살, 식물, 물잔 풍경. 타 앱의 캡처나 원본 일러스트를 추출하지 않았다.
하단 메뉴 아이콘은 Compose Canvas로 직접 그렸다. 글꼴은 시스템 SansSerif를 사용한다.

## 실행

Android Studio에서 기존 프로젝트를 열고 app을 다시 Run한다.
JDK 21.0.11과 기존 Gradle 캐시로 `:app:assembleDebug --offline` 빌드 성공을 확인했다.
자동 테스트는 추가하거나 실행하지 않았다. 새 디자인의 에뮬레이터·실기기 시각 확인은 미실행이다.

## 후속 화면 디테일 개선
로그인·회원가입·프로필에 기존 SOL 일러스트를 활용한 녹색 배너와 단계 표시를 추가했습니다. 동의 항목은 선택 상태가 구분되는 둥근 카드입니다. 내 정보는 흰색 배경의 프로필 카드, 일러스트 배너, 파스텔 기록 바로가기 3개로 구성했습니다. 실제 데이터가 없는 통계는 추가하지 않았습니다. 이번 후속 수정의 빌드·기기 확인은 아직 실행하지 않았습니다.

- 자동 테스트는 추가/실행하지 않았습니다. 기기 E2E, 실제 인증·메일·토큰·서버 저장은 미검증입니다.
- 실제 연동 담당은 성준이며 3.1은 프론트엔드 데모 구현 완료 · 서버 연동 대기입니다.

## 3.2 홈 적용

기존 흰색/녹색과 습관 일러스트를 유지하고 진행률·최근 식사·복약 일정·빠른 기록 시트를 추가했습니다. 카드별 오류와 재시도, 상태별 안내를 분리했습니다. 기록 화면 디테일 및 홈 진행률 연동을 포함합니다. 날짜는 현재 기기 기준이며 과거 날짜 조회는 제공하지 않습니다.

## 2026-10-16 · 홈 카드 디자인 보완

- 흰색 바탕 유지. 최근 식사에 피치 헤더/접시 그림, 다음 복약에 라벤더 헤더/캡슐·시계 그림 추가.
- 그림은 Compose Canvas로 직접 작성한 장식이며 실제 약/식사 사진이나 의료 안내가 아님.
- 오류는 옅은 안내 패널로 구분하고 기존 카드별 재시도 유지. 이동 버튼에 구분선과 원형 화살표 적용.
- 의약품 사전 이동을 민트 카드로 변경. API·데모 상태·광고 요청 변경 없음.
- 원본 Android Studio 프로젝트와 PR 작업 폴더에 동일 소스 반영. 이번 디자인 후속 변경은 아직 원격 PR에 게시하지 않음.
- 이번 변경의 APK 빌드 성공. 실제 기기 시각 확인은 대기.
